## 运行条件

- 说明将双击 HTML 作为分享入口，非 frontend/workbench.html。源码使用内嵌 module、现代 JavaScript、dialog.showModal、FileReader、Blob、对象 URL 和下载链接，需现代浏览器；实际支持矩阵待实测。
- localStorage 启动探测成功时使用浏览器存储，否则退回 Map 内存并显示临时模式（949–970）。file URL 与未来 HTTP/HTTPS 地址的数据空间不可假定相同；恢复上线不能只换入口就宣称旧数据自动迁移。
- JSON、Word、PowerPoint 在浏览器端生成文件。PDF 实际打开新窗口并调用浏览器打印，用户另存为 PDF，依赖弹窗、打印功能和字体（2433–2440、2506–2516）。复制优先 Clipboard API，失败走 execCommand，但后者返回值未检查（2518–2520）。
