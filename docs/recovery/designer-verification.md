## 范围与基准

用户批准机械恢复可维护源码和单 HTML 打包，保留全部现有功能，不改版、不新增功能。本检查限于界面结构、文案、视觉规则和交互呈现的一致性；不修改产品代码，不代替 Reviewer 的独立功能验证或 PM 的版本完成判断。

基准：`reference/2026-09-22/节拍工作台.html`、同目录 `使用说明.txt`，以及 `docs/recovery/designer-assessment.md` 的源码证据。本清单不代表浏览器实测结果。

## 构建就绪后的核对方法

1. 记录 PM 指定的恢复源码、打包 HTML、构建版本和访问方式，确认比较对象。
2. 对照原 HTML 与恢复产物的 DOM 结构、字段属性、文案、ID/class、导航 data 属性，以及全部 CSS 声明的顺序。机械拆分可更换文件组织，不能改变实际级联结果。
3. 在可用的浏览器检查条件下，用相同浏览器、视口、数据和系统偏好比较原版与恢复版。使用隔离的临时检查数据，不把原版浏览器存储误认为恢复版必须自动共享的数据。
4. 逐项记录证据和结果：一致 / 差异 / 未检查。源码一致与实际渲染一致分开记录；工具不可用时如实注明，不能以静态检查代替截图结论。
5. 将界面差异及影响交给 PM，由 PM 协调 Developer；设计检查发现的功能疑点交 Reviewer 独立核实。
