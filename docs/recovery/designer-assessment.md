## 页面与功能结构

这是单个 HTML 内的 8 个互斥功能视图，不是同时展示的双栏工作台。默认进入快速录入；`.feature-panel` 控制显隐，原 `.grid/.lower` 后被覆盖为 block（106–108）；导航结构在 853，视图主体在 859–912。

| 视图 ID | 入口与内容 | 必须保留的交互 |
|---|---|---|
| `work-entry` | 工作录入 → 快速录入；日期、标题、项目、类型、起止时间、计算时长、进度、产出、下一步 | 保存；编辑/取消编辑；痛点弹窗；快速会议；按项目待完成任务及追踪 |
| `work-backfill` | 工作录入 → 工作补录；项目、日期段、每日小时、可选说明、生成数量与工时预览 | 日期段含首尾且逐日生成，包含周末；默认 8h，每日 0.1–24h；原生成记录为项目整理、进度 100、09:00 起（2141–2205） |
| `daily-summary` | 工作总结 → 本日工作报告；日期、三项指标、按项目分组的当天记录、日报预览与项目占比 | 按日期更新；编辑/完成编辑；复制日报；原页没有周期报告的 Word/PPT/PDF 按钮 |
| `period-summary` | 工作总结 → 周度/月度/年度；日期与范围、投入小时/完成事项/项目数、报告、项目投入占比 | 只读→编辑→完成编辑；复制、Word、PowerPoint、PDF；切换周期或日期恢复自动报告 |
| `task-center` | 任务清单；按项目新增任务、项目分组、待完成计数 | 完成与恢复；与快速录入、心流及会议任务同步；保留来源与状态提示 |
| `work-records` | 工作记录 → 最近工作；日期、标题、类型、项目、时长、产出、痛点、解决方案、进度 | 日期倒序展示最近 8 条，但总计数为全部记录；编辑回填快速录入；删除需原生确认（1673–1692、2336–2357） |
| `dashboard` | 工作记录 → 数据可视化；今日/周/月/年四个 KPI、今日项目占比、今日概览、三张周期分析卡 | 蓝色平均进度、绿色下一步计划覆盖率；与记录及总结同源统计 |
| `flow-mode` | 独立心流入口；专注计时、项目、工作类型、任务草稿、完成与快速会议 | 进入即计时；暂离继续计时；返回不重置；完成写记录；项目非空时离页尽力保存；BFCache 不结束（1904–1982、2314–2318） |

四种工作类型保持原顺序：项目推进、会议讨论、对外协商、项目整理。项目输入通过共享 datalist 提供历史建议，仍允许自由输入。

## 弹窗与反馈

- 痛点弹窗：痛点、解决方案、已解决/未解决、处理说明/待跟进行动；“暂不设置”与“保存痛点”（915–925）。
- 用户与数据管理：当前用户、独立工作区列表及切换、新建用户、导出当前用户 JSON、导入至新的独立用户（926–936）；这是本地工作区切换，不能设计成在线账户或云同步。
- 会议结束弹窗：会议时长、项目、必填会议内容、产出、可逐条完成的任务；“不记录本次会议”与“保存会议记录”（937–947）。会议入口位于快速录入和心流，两处共享会议状态。
- Toast 位于底部中央；删除保留确认；校验、临时存储、计时状态必须可见。用户区分清楚“暂离心流”与“完成工作”。
- 项目任务追踪是另一条现有计时流程：再次点击停止；切换追踪项目先结束原项目；追踪项目任务全部完成时自动结束并记录（1227–1283）。不能在恢复时遗漏。

## 响应式与可访问性约束

- 900px：仪表盘、心流降为单列；周期分析卡纵排，KPI 一行四项。
- 560px：主区约 12px 边距；header 换行；心流入口独占导航第一行，其余菜单第二行；下拉覆盖导航宽度并限制高度滚动；表单单列，日报单列，导出两列；卡片 22px 圆角；任务长文换行；弹窗动作可换行。
- 360px：部分报告控件各占整行，周期指标与导出单列；心流顶栏动作纵排。
- 原版已有减少动态、减少透明度、高对比、无 backdrop-filter 兼容、打印样式（804–846 附近）；保真恢复须保留相应退化路径。
- 导航同时支持 hover、focus-within 和触摸点击；触摸点击打开后选子项，外点/Escape 关闭；保留 aria-controls、aria-expanded、aria-current 与明确字段标签（2269–2329）。

## 易被重构改变的行为

1. 周报采用独立固定模板：本周工作总结、下一步计划、团队沟通、附件、自身评价、备注；月/年仍为原结构模板，日报保持原模板。周报附件存在特殊字符，应记录原样并由 PM 决定是否另列缺陷，首轮不擅改（1540–1582）。
2. 周期报告全文自动增减高度、隐藏内部纵向滚动且不可手动 resize；输入、窗口 resize、切换至报告时重算，不能改为截断卡片（666–681、1668–1672）。日报未使用同一自动高度机制。
3. 报告手动编辑是当前预览状态，不能暗示为独立永久保存文档；周期/日期/用户切换会恢复生成流程。复制及各格式导出直接读取当前报告 textarea（1700–1714、2518–2546）。
4. 同一天时段按时间并集计算总工时；同项目重叠不重复，多项目重叠均分项目占比，断档不计入。不能简单累加每条 hours（1354–1377）。
5. 导入恢复为新用户并切换过去，不能覆盖/合并当前工作区；v3 备份含 profile、records、tasks，同时兼容旧数组输入（1763–1807）。
6. 心流离页保存依赖浏览器事件，强杀/断电不保证；项目空、时长异常不保存，重复离页事件不重复落记录；暂离不等于暂停。文案与状态语义需保持。
7. 默认始终快速录入；运行期间 hash 可切视图，但初始化会重设 `#work-entry`，不能未经 PM 同意改变为恢复上次页面（2265–2335）。
8. 本地存储键含旧日志键、用户列表、当前用户、每用户日志与任务；迁移入口/域名可能改变浏览器存储可达性。设计交付不应承诺自动跨来源迁移；保留 JSON 备份恢复入口及现有说明（949–1048）。
