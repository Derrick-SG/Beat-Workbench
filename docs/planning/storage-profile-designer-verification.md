## 需Developer处理或确认的差异

1. **头像选择不可通过标准键盘按钮访问（优先修复）。** AX树“选择头像”为text，源码使用label加hidden file input，无button/tabindex/键盘处理。鼠标可点不能替代键盘可达；改成有可访问名称的button触发选择器，或使用可聚焦的原生文件控件。保留清楚焦点状态。
2. **默认头像为棋子，不是人物占位。** bootstrap的avatar()无图时写入`♙`，截图可见国际象棋兵。UI规格要求自绘通用人物占位；应替换为简洁人物图形，并在头像邻接姓名时继续作为装饰。
3. **草稿确认只提供放弃/返回，不提供保存并继续。** guardDraft使用原生confirm；与UI规格三选项“继续编辑/放弃更改/保存并继续”不一致。建议落实同弹窗确认视图，失败时保持原正式资料、草稿及当前用户/来源；若需缩减交互由PM明确裁定，不能视为已符合。
4. **目录操作未按来源/状态收敛。** 浏览器模式截图同时出现重新连接、改用浏览器存储、原浏览器数据、重试、上一快照、恢复独立副本、重新加载等操作。建议仅启用/显示当前状态适用操作，浏览器模式主操作为选择文件夹及备份；目录异常出现相关恢复动作。当前浏览器模式“此文件夹保存全部工作区”宜改条件性说明，避免误解已连接。
5. **存储文字密度过高。** 桌面截图中来源/时间/权限说明行距紧挤，与资料区较大留白不平衡。原`.dialog-body p`负margin会作用新增p；新增存储区应重置段落margin，以连续可读行距和8px左右纵向间距组织来源、时间、说明，避免以堆叠按钮替代状态层级。
