在用户数据管理页面增加可选择存储目录、重开读取目录数据，以及修改用户名和圆形头像。用户接受纯网页分级支持，确认书面方案和实施计划，并授权独立测试通过后发布 V1.1.0、生成分享包、上传 GitHub。
