# Beat-Workbench V1.1.4 阶段记忆

日期：2026-11-25（Asia/Shanghai）。状态：开发代码已冻结，最终版本包、真实授权和 GitHub 同步待核对；不得据此宣称全部完成。

## 目标与决策

用户确认 V1.1.4 仅在本机固定 4173 入口连接自己的 ChatGPT 账号与合资格套餐，辅助生成日、周、月、年工作总结。生成前完整预览并确认发送当前用户、当前报告范围的已保存工作记录；只发送日期、标题、项目、工时、产出、下一步和进度。生成稿可编辑、保存为本期报告、恢复自动报告。公开静态演示和单 HTML 分享包不启用 AI 连接；不发送头像、其他用户、未保存草稿、会议正文、痛点详情或 Notion 数据。

Reviewer 指出年报原实现的 500 条/100 KiB 上限会阻止真实规模工作区生成。Developer 改为有界分批、分层合成及取消机制，前端完整预览并说明预计批数和阶段错误。任一批失败或取消都不返回可保存的局部草稿。服务有 16 MiB 请求上限，超限明确提示；真实 OpenAI 套餐资格、授权回调与生成尚未由用户实测。

## 角色结果与验证

Designer 提供报告预览、连接状态和可编辑草稿的界面方案。Developer 在独立 worktree 实现本机 OAuth 服务、报告范围投影、前端交互、持久化与 v5 备份兼容。开发阶段全量自动测试 165/165 通过，构建与 diff 检查通过；最终版本包仍待 Reviewer 复核。Reviewer 独立复核了白名单、账号/范围隔离、PKCE/state/nonce、令牌保护、566 条及 2001 条合成分批、429/取消失败路径，并发现且推动修复批次数估算边界。隔离 4312 页面使用合成数据验证普通工作记录与本日报告；AI 交互只在 4173 启用，因此真实授权及完整浏览器端到端仍列为未测。测试未发送个人工作记录。

## 旧账户数据调查

用户反馈 4173 无法使用旧账户。主线程确认当前 ChatGPT 内置浏览器显示“当前浏览器 · 已就绪”及空白“我的工作台”；4173 服务本身来自正确项目目录。旧工作区 JSON 仍在用户指定数据文件夹，校验通过；该目录文件和上一份快照已复制到独立恢复目录。来源设置与目录句柄保存在每个浏览器自己的 IndexedDB，内置浏览器与桌面 Chrome/Edge 即使打开同一 4173 地址也不共享授权。Reviewer 核实对已有目录选择“使用目标数据”只读入旧工作区并保存目录句柄，不覆盖旧 JSON。用户需在常用桌面浏览器自行选择原目录、核对摘要并连接；未代为写入或迁移个人数据。旧目录含一条待恢复会议会话，连接后应按页面恢复提示核对，不随意放弃。
