## 本次修复与依据

用户报告心流页面“会议结束，补充会议记录”弹窗中已填写项目、内容、产出和任务后无法保存。隔离审查确认根因：保存进行中或已有待恢复副本时，`src/bootstrap.js` 的全局捕获保护层会在会议表单监听器之前静默阻止提交；原保存路径还可能在异步写入前关闭弹窗。

修复允许会议表单接收提交事件，并在统一保存队列正在写入或已有待恢复副本时保留弹窗和已填草稿，提示用户等待、重试或导出，避免静默无响应和伪造成功。新增 `tests/meeting-save-guard.test.mjs` 覆盖检查点保存中与待恢复副本两种边界；完整隔离自动测试 140/140 通过。Reviewer 独立审查该修复及来源恢复相关 9 项回归通过。未访问 4173、个人数据、真实目录或真实存储文件。
